# Instruções para Codex e agentes futuros

## Entrega de arquivos ao usuário

Preferência explícita do usuário, registrada em 2026-10-02:

- Quando o usuário solicitar um ZIP ou outro arquivo para download, entregar o arquivo diretamente na conversa, como anexo ou link de download direto do próprio arquivo.
- Links para o repositório, branches, páginas do GitHub Actions ou caminhos internos do workspace podem complementar a entrega, mas não a substituem.
- Se os resultados estiverem no GitHub Actions, baixar o artefato e disponibilizar o arquivo na conversa.
- Conferir que o arquivo existe e que o ZIP pode ser aberto antes de declarar a entrega concluída.
- Se o ambiente não permitir essa entrega, explicar a limitação concretamente e oferecer a alternativa disponível. Não afirmar que um arquivo foi anexado sem disponibilizá-lo.

Estas instruções se aplicam a agentes que trabalhem neste workspace ou repositório; não alteram configurações globais da conta.
